# CGPA Calculator

A simple and user-friendly web application to calculate Cumulative Grade Point Average (CGPA) for students.

## Features

- Easy-to-use interface for calculating CGPA
- Input fields for course grades and credits
- Real-time calculation of CGPA
- Responsive design that works on desktop and mobile devices
- Clean and modern user interface with CSS styling
- Clear display of final CGPA results

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the `index.html` file in your web browser
2. Enter your course grades and corresponding credits
3. The calculator will automatically compute your CGPA
4. View your final CGPA result instantly

## Project Structure

```
├── index.html      # Main HTML file
├── style.css       # CSS styling
├── script.js       # JavaScript functionality
└── README.md       # Project documentation
```
